# Getting Started with 3D Printing

## Prerequisites

- 3D printer (FDM or SLA)
- Slicing software (e.g., Cura, PrusaSlicer, Bambu Studio)
- CAD software for design (optional - FreeCAD, Fusion 360, etc.)

## Initial Setup

1. **Prepare your printer** - Ensure proper calibration and bed leveling
2. **Select material** - Choose appropriate filament/resin for your project
3. **Slice your model** - Use slicing software to prepare for printing
4. **Print and monitor** - Start print and observe for issues
5. **Post-processing** - Remove supports, sand, paint as needed

## Resources

- Check the designs folder for ready-to-print models
- Review design guidelines before creating custom prints
